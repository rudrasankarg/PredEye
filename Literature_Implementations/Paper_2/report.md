# Paper 2: Using Large Language Models to Accelerate Communication

## Dataset
- **Name:** Conversational Text Datasets
- **Size:** Large-scale corpora of dialogue
- **Details:** Text preprocessed and tokenized for LLM fine-tuning.

## Algorithms & Models
- **Model:** Large Language Model (Transformer-based)
- **Task:** Abbreviation expansion (e.g., "h a y" -> "how are you").

## Implementation Details
- **Optimization Technique:** AdamW optimizer
- **Regularization:** Weight decay, Dropout.
- **Metrics:** Motor actions saved (%), Accuracy, F1 Score (Text generation quality).
- **Training:** Fine-tuning on domain-specific dialogs.

## Results
- **Accuracy:** ~94.2%
- **F1 Score:** ~0.93
- **Motor Actions Saved:** 57%
